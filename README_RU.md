# Echo Combine Extension

Улучшенный форк расширения [Echo Combine Extension](https://github.com/dutixlf/echo-combine-extension) для музыкального плеера [Echo](https://github.com/brahmkshatriya/echo).

Расширение позволяет объединить метаданные одного музыкального сервиса с аудиопотоками другого. В форке улучшены выбор источников, поиск совпадений между треками, кэширование и система резервных источников.

## ✨ Возможности

### 🎵 Раздельные источники метаданных и аудио

- Использование одного расширения для метаданных, поиска, альбомов, исполнителей, плейлистов и ленты библиотеки.
- Использование другого расширения для получения аудиопотоков.
- Выбор основного источника аудио и до четырёх резервных источников.

### ⚡ Режим First Available

- Включён по умолчанию.
- Проверяет источники аудио в порядке приоритета и использует первый, в котором найден воспроизводимый трек.
- Переходит к следующему источнику, если предыдущий не нашёл трек или слишком долго отвечает.
- Сохраняет исходные уровни качества основного источника, не смешивая их с потоками других сервисов.

Например, если Deezer предоставляет `FLAC`, `320 кбит/с` и `128 кбит/с`:

| Подключение | Настройка качества в Echo | Ожидаемое качество |
|---|---|---|
| Wi-Fi | Highest | FLAC |
| Мобильный интернет | Medium | 320 кбит/с |
| Мобильный интернет | Lowest | 128 кбит/с |

### 🔄 Система резервных источников

- Настройка дополнительных источников в порядке приоритета.
- По умолчанию от резервного источника используется только поток с наивысшим качеством.
- Это позволяет, например, использовать YouTube Music в качестве резерва и получать максимальное доступное качество независимо от настройки Medium или Lowest в Echo.
- При необходимости можно добавить источник метаданных в список дополнительных источников аудио.

### 🎯 Умный поиск совпадений треков

Вместо безусловного выбора первого результата поиска расширение оценивает кандидатов по нескольким критериям:

- **ISRC** — точное совпадение идентификаторов записи получает наивысший приоритет.
- **Название трека** — нормализуется для уменьшения влияния пунктуации, регистра и распространённых суффиксов.
- **Исполнитель** — учитываются полные и частичные совпадения имени.
- **Длительность** — близкая продолжительность повышает оценку совпадения.
- **Версия трека** — учитываются различия в тегах `Live`, `Remix`, `Acoustic`, `Instrumental`, `Karaoke`, `Cover`, `Slowed`, `Sped Up`, `Nightcore` и других поддерживаемых вариантах.

Расширение оценивает наиболее подходящие результаты и выбирает первый из проверенных кандидатов, для которого удалось получить аудиопотоки.

### 🚀 Кэширование и производительность

- LRU-кэш в оперативной памяти размером до 200 записей.
- Успешные совпадения кэшируются на 30 минут.
- Неудачные поисковые запросы кэшируются на 5 минут.
- Поиск в каждом источнике ограничен таймаутом в 12 секунд.
- Если основной источник не отвечает в течение 4 секунд, может начаться проверка следующего источника.
- Результаты запросов, завершившихся по таймауту, не кэшируются, поэтому их можно проверить повторно.

### 🛠️ Настройки

| Настройка | По умолчанию | Описание |
|---|---|---|
| Metadata Extension | Первый доступный источник | Выбор источника метаданных и операций с библиотекой. |
| First Available Mode | Включено | Использование первого источника, в котором найден воспроизводимый трек, вместо объединения потоков всех источников. |
| Fallback Sources: Best Quality Only | Включено | Использование только потока наивысшего качества от резервного источника. |
| Include Metadata Extension As Fallback Stream | Выключено | Разрешает использовать источник метаданных как дополнительный источник аудио. |
| Preferred Stream Extension | Первый доступный источник | Выбор основного источника аудио. |
| Alternative Stream Extensions | Не настроены | Выбор дополнительных источников аудио в порядке приоритета. |

## ⚙️ Рекомендуемая настройка

Пример конфигурации со Spotify для метаданных и Deezer для аудио:

1. Установи необходимые расширения в Echo.
2. Открой **Настройки → Расширения → Combine Extension**.
3. В поле **Metadata Extension** выбери Spotify.
4. В поле **Preferred Stream Extension** выбери Deezer.
5. При необходимости добавь YouTube Music или другой совместимый источник в качестве резервного.
6. Включи **First Available Mode** и **Fallback Sources: Best Quality Only**.
7. В настройках качества плеера Echo установи **Highest** для Wi-Fi и **Medium** для мобильного интернета.

Фактическое качество зависит от аудиопотоков, доступных у выбранного источника.

3. Установи совместимый пакет расширения с помощью поддерживаемого Echo способа установки.

Если готовая сборка отсутствует, потребуется самостоятельно собрать проект.
